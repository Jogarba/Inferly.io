# 📊 Inferly

> **Tu asistente de estadística, siempre contigo.**

Inferly es una aplicación para Android diseñada para ayudar a estudiantes a **calcular, comprender y aprender estadística** de una manera rápida y sencilla.

La aplicación combina herramientas de análisis estadístico con **Alfred**, un tutor de inteligencia artificial capaz de explicar conceptos, mostrar los pasos de los cálculos y ayudar a interpretar los resultados.

## ✨ Características

### 📊 Herramientas estadísticas

Inferly incluye diferentes herramientas para resolver ejercicios de estadística:

* **Pruebas de hipótesis**

  * Pruebas para medias
  * Pruebas para proporciones
  * Una muestra
  * Dos muestras
  * ANOVA

* **Intervalos de confianza**

  * 90 %
  * 95 %
  * 99 %

* **Diferencia de medias**

  * Comparación entre dos grupos.

* **Diferencia de proporciones**

  * Comparación entre dos proporciones.

* **Varianza**

  * Prueba de varianza de una muestra.
  * Comparación de varianzas entre dos poblaciones.

* **Pruebas de Chi-cuadrado**

  * Bondad de ajuste.
  * Independencia.
  * Homogeneidad.

Las herramientas están pensadas para obtener resultados de forma rápida y, al mismo tiempo, facilitar la comprensión del procedimiento estadístico.

---

## 🤖 Alfred — Tutor de IA

Uno de los componentes principales de Inferly es **Alfred**, un tutor de inteligencia artificial especializado en estadística.

Alfred puede ayudarte a:

* Resolver preguntas teóricas.
* Resolver ejercicios prácticos.
* Explicar los cálculos paso a paso.
* Interpretar los resultados obtenidos.
* Comprender conceptos estadísticos.
* Resolver dudas mediante conversaciones en lenguaje natural.

Alfred está diseñado para explicar los conceptos de forma clara y directa, evitando respuestas excesivamente técnicas.

### 💬 Ejemplo

**Pregunta:**

> ¿Cuándo rechazo la hipótesis nula?

**Alfred:**

> Rechazas H₀ cuando el estadístico calculado cae fuera de la región crítica. Por ejemplo, con α = 0.05 en una prueba bilateral, los valores críticos son ±1.96.

Inferly está orientada principalmente a estudiantes que necesitan una herramienta para:

## 🎯 Objetivo

El objetivo de Inferly es convertirse en una herramienta práctica para estudiantes que necesitan aprender estadística sin depender únicamente de fórmulas o calculadoras.

La aplicación busca combinar:

```text
Cálculo estadístico
        +
Explicación paso a paso
        +
Tutor de IA
        ↓
Aprendizaje de estadística
```
